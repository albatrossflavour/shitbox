## Critical Anti-Patterns (do NOT repeat these)

- **Don't commit with a misleading message**: I bundled the tile tool into what I called a "dashboard + sse" commit and had to amend. When staging for a commit, either stage selectively with explicit paths OR update the message to cover what's actually there — don't split intent from message. (advisory)
- **Don't hack DPI to mask CSS sizing issues**: `--force-device-scale-factor=1` is only correct when the CSS is tuned to the real viewport. Brain's prior "don't hack DPI" guidance was about doing it *instead of* tuning CSS — doing both together is the right kiosk setup. (advisory)
