typewriter text). This plan fixes the packaging hole BEFORE the code in
Plan 02 starts pointing at the assets, so Plan 02 can't ship broken even
transiently. Per SC-3, `TitleCardConfig` shape stays untouched.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream TTF → repo | The fetched Cinzel TTF and OFL.txt cross from an external HTTPS source (NDISCOVER or google/fonts) into the committed codebase. Once committed, they become part of the project's trusted asset set. |
| vendored TTF → Pillow (FreeType) | At slate render time, Pillow's `ImageFont.truetype` parses the bundled TTF via libfreetype. A malformed or malicious font file could in principle crash Pillow or trigger a freetype bug. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01-01 | Tampering | Vendored TTF files | mitigate | Fetch only over HTTPS from NDISCOVER or google/fonts upstream repos (both published OFL sources referenced by Cinzel's own licence header). Commit raw bytes; no transform step that could silently alter the file. Reviewer spot-checks `file` output reports "TrueType Font data" on both TTFs. |
| T-27-01-02 | Denial of service | Malformed TTF crashing Pillow/FreeType at render time | accept | Existing `_font(path, size)` helper in `title_card.py:311-316` already wraps `ImageFont.truetype` in try/except and falls back to `ImageFont.load_default()`. A broken TTF produces bitmap typewriter text on the slate, not a daemon crash. Plan 02 preserves this fallback; no new mitigation needed at the packaging layer. |
| T-27-01-03 | Information disclosure | OFL.txt licence compliance | mitigate | Ship `OFL.txt` verbatim alongside the TTFs (per SIL OFL 1.1 Section 5). `pyproject.toml` glob explicitly names the licence file so a wheel build can't strip it. |
| T-27-01-04 | Supply chain | Upstream repo compromised between pull and commit | accept | Low-value target (a free font used for video title cards on a hobby rally telemetry project). No runtime network fetch — the TTF is pinned in-tree once committed. An upstream compromise would have to coincide with a fresh fetch, which only happens at phase-implementation time and is reviewed. |
</threat_model>
