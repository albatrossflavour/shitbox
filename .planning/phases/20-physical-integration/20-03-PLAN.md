<task type="auto" tdd="false">
  <name>Task 2: Design ELP camera cradle in OpenSCAD</name>
  <files>hardware/camera-bracket.scad</files>
  <read_first>
    - hardware/sensor-cluster.scad (reference analog — reuse conventions)
    - .planning/phases/20-physical-integration/20-PATTERNS.md (naming conventions, boolean margins)
    - .planning/phases/20-physical-integration/20-RESEARCH.md (print orientation pitfall 4)
  </read_first>
  <action>
    Create `hardware/camera-bracket.scad` following sensor-cluster.scad conventions.

    **File structure:**

    1. File header: project name, part description ("ELP 4K front camera dash cradle"),
       orientation note ("Base flat on bed, lens aperture faces forward when installed"),
       measured dimensions with date, units: mm.

    2. `$fn = 64;`

    3. Constants blocks:

       Camera PCB block — from Task 1 measurements:
       ```
       CAM_PCB_W      = <measured>;
       CAM_PCB_H      = <measured>;
       CAM_PCB_T      = <measured>;
       CAM_LENS_D     = <measured>;
       CAM_LENS_PROT  = <measured>;
       CAM_HOLE_D     = <measured>;
       CAM_HOLE_SPG   = <measured>;
       CAM_HOLE_INSET = <measured>;
       ```

       Cradle construction:
       ```
       CRADLE_WALL  = 2.0;   // wall thickness (matches OUTER_WALL convention)
       CRADLE_TOL   = 0.5;   // clearance around PCB
       CRADLE_FLOOR = 2.0;   // base thickness
       ```

       Dash mount:
       ```
       BOLT_D       = 4.5;   // M4 clearance
       BOLT_HEAD_D  = 8.5;   // M4 counterbore
       ```

    4. Module `camera_bracket()` — a simple cradle (per D-14: bracket only, no full enclosure):
       - Base plate sized to camera PCB + tolerance + wall thickness
       - Three side walls (left, right, bottom) — the top is OPEN (no enclosure, per D-14)
       - Lens aperture: circular cutout in the front wall (or front wall is absent entirely
         if the lens protrudes beyond the cradle front — measure lens protrusion vs wall height)
       - PCB retention: two small clips or a ledge that the PCB slides into from the top
       - If the camera has mounting holes: posts with pilot holes matching the PCB holes
       - If no mounting holes: friction-fit cradle with PCB resting on a shelf
       - USB cable exit slot in the appropriate wall (from Task 1 measurements)
       - Two M4 bolt holes in a base flange for dash mounting (per D-13)
       Minus:
       - Lens aperture (if front wall present)
       - Bolt holes with counterbore
       - USB cable exit slot

    **Design rules:**
    - This is a CRADLE not an ENCLOSURE (per D-14) — open top, minimal material
    - Keep it simple: the camera just needs to not move. No complex features
    - Base flange extends beyond the cradle body for dash bolt access
    - Boolean conventions: `+ 0.2` depth, `-0.1` entry face
    - Print base-down, no supports needed for a simple cradle shape
  </action>
