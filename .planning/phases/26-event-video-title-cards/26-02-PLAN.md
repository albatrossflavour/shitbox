| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-02-01 | Tampering | config/config.yaml whimsy_lines | accept | Config is source-controlled; operator edits require shell access to the Pi. No runtime write path. |
| T-26-02-02 | Denial of Service | Extremely long whimsy_lines entries | mitigate | Renderer (plan 26-03) applies a length clamp before passing to Pillow; config loader does not need to enforce. Documented here so clamp ownership is clear. |
| T-26-02-03 | Elevation of Privilege | _dict_to_dataclass unknown keys | accept | Existing pattern silently ignores unknown keys (same behaviour as every other *Config dataclass); no new attack surface. |
