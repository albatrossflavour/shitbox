**Part A: Add fuel stop layer to initMap()**

Inside the `initMap()` function, AFTER the existing event markers loop (the `for` loop that
iterates over `eventsData` and creates `L.circleMarker` for each event), add the fuel stop
rendering block:

```js
// Fuel stop pins
if (fuelData && fuelData.length > 0) {
    var cumDist = 0, cumVol = 0;
    for (var fi = 0; fi < fuelData.length; fi++) {
        var stop = fuelData[fi];
        if (stop.lat == null || stop.lng == null) continue;

        // Compute running average km/L
        var cumAvgKml = null;
        if (fi > 0 && stop.odometer_km != null && fuelData[fi - 1].odometer_km != null) {
            var dist = stop.odometer_km - fuelData[fi - 1].odometer_km;
            if (dist > 0) {
                cumDist += dist;
                cumVol += stop.volume_litres;
                cumAvgKml = (cumDist / cumVol).toFixed(1);
            }
        }

        var fDate = new Date(stop.timestamp_utc);
        var fDateStr = fDate.toLocaleDateString('en-AU', { timeZone: TIMEZONE });
        var fTimeStr = fDate.toLocaleTimeString('en-AU', { timeZone: TIMEZONE, hour: '2-digit', minute: '2-digit' });

        var fPopup = [
            '<div class="map-popup">',
            '<div class="popup-type" style="color:#c06000">Fuel Stop</div>',
            '<div class="popup-detail">',
            fDateStr + ' ' + fTimeStr,
            '<br>Volume: ' + stop.volume_litres.toFixed(1) + ' L',
            '<br>This stop: ' + (stop.km_per_litre != null ? stop.km_per_litre.toFixed(1) + ' km/L' : '\u2014'),
            '<br>Running avg: ' + (cumAvgKml != null ? cumAvgKml + ' km/L' : '\u2014'),
            '</div></div>'
        ];

        L.circleMarker([stop.lat, stop.lng], {
            radius: 8,
            fillColor: '#c06000',
            color: '#fff',
            weight: 2,
            opacity: 0.9,
            fillOpacity: 0.85
        }).bindPopup(fPopup.join('')).addTo(map);
    }
}
```

Key details:
- `fillColor: '#c06000'` is the site accent orange (per UI-SPEC D-07).
- The cumulative average algorithm: first stop always has `cumAvgKml = null` because there
  is no prior odometer reading to calculate distance from. Display as em dash `\u2014`.
- `km_per_litre` for the first stop is also null — same em dash treatment.
- Variable names prefixed with `f` (fDate, fDateStr, etc.) to avoid collisions with the
  event marker loop variables.
- No `cost` field is referenced anywhere. Only `volume_litres`, `km_per_litre`, `odometer_km`,
  `lat`, `lng`, `timestamp_utc` are accessed. This enforces the cost data hard exclusion (D-08).
- Uses `var` declarations throughout (no `const`/`let`).
