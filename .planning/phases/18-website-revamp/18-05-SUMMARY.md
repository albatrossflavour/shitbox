# Phase 18 Plan 05: Rally Summary Metrics in Prometheus

Pushes 6 new current-state gauges to Prometheus each sync cycle so the Grafana dashboard
shows operational rally data alongside sensor telemetry.

## What Was Done

### New metrics

| Metric | Labels | Source |
| ------ | ------ | ------ |
| `shitbox_events_total` | `type` | EventStorage filesystem scan |
| `shitbox_fuel_stops_total` | none | `COUNT(*) FROM fuel_stops` |
| `shitbox_fuel_litres_total` | none | `SUM(volume_litres) FROM fuel_stops` |
| `shitbox_fuel_efficiency_kml` | none | `(max_odo - min_odo) / total_litres` |
| `shitbox_notes_total` | none | `COUNT(*) FROM notes` |
| `shitbox_active_driver` | `name` | `driver_stints WHERE ended_at IS NULL` |

### Python changes (shitbox repo — commit bcb0e86)

**`database.py`**: Three new aggregate read methods:
- `get_fuel_summary()` — count, total litres, km/L efficiency
- `get_notes_count()` — COUNT from notes table
- `get_active_driver_name()` — driver_name WHERE ended_at IS NULL

**`events/storage.py`**: `count_events_by_type()` scans `base_dir/<day>/*.json`, groups by
`meta["type"]`, skips malformed files silently.

**`sync/batch_sync.py`**: `_build_summary_metrics()` assembles all 6 gauges using `now_ms`
timestamp (not cursor-based). `_sync_summary()` encodes and POSTs without retry logic — errors
are logged at WARNING and do not block the batch sync path. `_sync_summary()` called in
`_sync_loop()` after `_sync_batch()`, inside the `is_connected` guard.

**`events/engine.py`**: `event_storage=self.event_storage` wired into `BatchSyncService`
at init. `event_storage` is already present at that point in the constructor.

**`tests/test_batch_sync_metrics.py`**: 5 new tests in `TestSummaryMetrics`, TDD red→green:
- `test_summary_empty_db` — zero defaults, no active_driver when none set
- `test_summary_fuel_counts` — count=2, total=83.7 L
- `test_summary_notes_count` — count=1
- `test_summary_active_driver` — label name="Tony", value=1.0
- `test_summary_event_counts` — HIGH_G=2, HARD_BRAKE=1 from temp JSON files

### Grafana dashboard (home-ops — commit 1eff9469)

RALLY SUMMARY row added at y=49 in `/tmp/build_dashboard.py`. 7 new panels:

- **Event Counts** (barchart, w=12): `shitbox_events_total` with `{{type}}` legend, badge colours
  per event type (HIGH_G red, BIG_CORNER amber, HARD_BRAKE red, ROUGH_ROAD purple, MANUAL green, BOOT blue)
- **Fuel Stops** (stat, w=3): count
- **Total Fuel** (stat, w=3): litres
- **Efficiency** (stat, w=3): km/L with green/amber/red thresholds at 8/12
- **Notes** (stat, w=3): count
- **Active Driver** (stat background, w=12): `label_replace` trick surfaces driver name as stat value

36 total panels (up from 29). JSON generated by `python3 /tmp/build_dashboard.py` and committed.
Flux reconciles to Grafana on push to home-ops main.
