**Step 1: GET current dashboard JSON**

```bash
curl -s -H "Authorization: Bearer $GRAFANA_API_KEY" \
  "https://grafana.shit-of-theseus.com/api/dashboards/uid/shitbox-rally-command" \
  | python3 -m json.tool > /tmp/grafana-dashboard.json
```

Inspect the JSON. Identify:
- The `dashboard` object (contains `panels` array)
- The Temperatures panel (id: 41 or search for title "Temperatures")
- The "Cabin Air Quality" panel (id: 44)
- The stat strip panels at y=5 (row 2)
- The current `version` field (needed for overwrite)

**Step 2: Modify the dashboard JSON**

Make these changes to the `dashboard.panels` array:

**A. Update Temperatures panel (title: "Temperatures")**

Add two new targets (Prometheus queries) to the existing panel's `targets` array:

```json
{
  "expr": "shitbox_temp{probe=\"exterior\"}",
  "legendFormat": "DS18B20 Exterior",
  "refId": "D"
},
{
  "expr": "shitbox_temp{probe=\"engine_bay\"}",
  "legendFormat": "DS18B20 Engine Bay",
  "refId": "E"
}
```

Add colour overrides in the panel's `fieldConfig.overrides` array:

```json
{
  "matcher": { "id": "byName", "options": "DS18B20 Exterior" },
  "properties": [{ "id": "color", "value": { "fixedColor": "#1f6feb", "mode": "fixed" } }]
},
{
  "matcher": { "id": "byName", "options": "DS18B20 Engine Bay" },
  "properties": [{ "id": "color", "value": { "fixedColor": "#d29922", "mode": "fixed" } }]
}
```

**B. Add new Ambient Light panel**

Create a new timeseries panel:

```json
{
  "type": "timeseries",
  "title": "Ambient Light",
  "gridPos": { "h": 7, "w": 8, "x": 16, "y": 30 },
  "targets": [
    {
      "expr": "shitbox_lux",
      "legendFormat": "Lux",
      "refId": "A"
    }
  ],
  "fieldConfig": {
    "defaults": {
      "unit": "lux",
      "color": { "fixedColor": "#d29922", "mode": "fixed" },
      "custom": {
        "lineWidth": 1,
        "fillOpacity": 10,
        "spanNulls": true,
        "axisCenteredZero": false,
        "showPoints": "never"
      }
    },
    "overrides": []
  },
  "options": {
    "legend": { "displayMode": "list", "placement": "bottom" },
    "tooltip": { "mode": "single" }
  }
}
```

The `gridPos` should place it next to the Cabin Air Quality panel. If Cabin Air Quality is
at `w=24` (full width), reduce it to `w=16` and place Ambient Light at `x=16, w=8`.

Use `id` = `max(existing panel IDs) + 1` for the new panel.

**C. Reorganise stat strip (if panel y positions allow)**

The stat panels at y=5 currently mix system and environment. Group them:
- System status panels (GPS fix, Sats, Throttle, CPU Temp, Disk Free, CPU %) — keep together
- Environment panels (Cabin temp, Pressure, Humidity, Power) — move to a separate row

This is a `gridPos.y` adjustment only. Use Claude's discretion on exact positioning based
on the actual dashboard JSON. The goal is logical grouping, not pixel perfection.

**Step 3: POST updated dashboard**

```bash
python3 -c "
import json
with open('/tmp/grafana-dashboard.json') as f:
    data = json.load(f)
dashboard = data['dashboard']
dashboard.pop('id', None)
payload = {
    'dashboard': dashboard,
    'overwrite': True,
    'folderId': data.get('meta', {}).get('folderId', 0)
}
with open('/tmp/grafana-update.json', 'w') as f:
    json.dump(payload, f)
"

curl -s -X POST \
  -H "Authorization: Bearer $GRAFANA_API_KEY" \
  -H "Content-Type: application/json" \
  -d @/tmp/grafana-update.json \
  "https://grafana.shit-of-theseus.com/api/dashboards/db" \
  | python3 -m json.tool
```

Verify the response contains `"status": "success"`.
