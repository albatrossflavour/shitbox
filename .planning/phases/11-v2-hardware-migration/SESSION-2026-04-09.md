## Two bugs found and fixed post-phase

### Bug 1: pip camera crash loop (`34eb566`)

**File:** `src/shitbox/capture/ring_buffer.py`
**Problem:** ffmpeg command included `-i /dev/camera-cabin` unconditionally. When the Brio
100 isn't connected, ffmpeg exits immediately, creating a defunct restart loop.
**Fix:** Added `os.path.exists(self.pip_device)` guard before including cabin camera in
ffmpeg command. Logs `pip_camera_absent_single_camera_mode` when degrading.

### Bug 2: health monitor thread dies silently (`7d88246`)

**File:** `src/shitbox/capture/ring_buffer.py`
**Problem:** `_health_monitor()` while loop had no try/except. Any exception (GPIO buzzer,
OSError, etc.) killed the watchdog thread permanently. Observed: ffmpeg stalled at 16:21,
health monitor died silently, stalled process ran for 63+ minutes with no recovery.
**Fix:** Wrapped loop body in try/except. Exceptions now log `health_monitor_cycle_error`
and the loop continues. Thread can no longer die silently.
