<objective>
Design the Waveshare 7-inch screen bezel and dash mounting bracket in OpenSCAD, ready for
PETG printing.

Purpose: Mount the Waveshare 7" HDMI LCD (H) on the passenger-side dash of the rally car
(right-hand drive, so passenger is on the left). The bezel protects the screen edges and
provides a VESA 75mm backplate for mounting. The bracket bolts directly to the dash with no
articulating joints (D-10) at a fixed angle suitable for co-driver touch interaction (D-11).

Output: `hardware/screen-bezel.scad` and `hardware/dash-bracket.scad` — two separate
OpenSCAD files for independent printing.
</objective>



       Bezel construction:
       ```
       BEZEL_WALL   = 2.0;    // lip width wrapping screen edges
       BEZEL_LIP    = 1.5;    // lip depth overlapping glass face (retention)
       BEZEL_TOL    = 0.5;    // clearance around screen case
       BACKPLATE_T  = 3.0;    // backplate thickness (structural)
       ```

       Connector exit block — from Task 1 measurements:
       ```
       HDMI_EXIT = [<width>, <height>]; // sized for HDMI connector + cable
       USB_EXIT  = [<width>, <height>]; // sized for USB connector + cable
       AUDIO_EXIT_D = 8;                // 3.5mm jack + plug clearance
       ```

    4. Derived dimensions.

    5. Render entry: `screen_bezel();`

    6. Module `screen_bezel()` — single piece combining:
       - Front frame with retention lips on all four sides (per D-09). Lips overlap the glass
         face by `BEZEL_LIP` mm on each side. The frame is open in the centre to expose the
         glass visible area
       - Side walls wrapping the screen case depth
       - Rear backplate — solid plate behind the screen with VESA 75mm hole pattern
         (4x M4 clearance holes with bosses). The bosses protrude from the back face by
         `VESA_BOSS_H` so a bracket can sit flat against the bosses
       Minus:
       - Glass viewing window (full GLASS_W x GLASS_H opening through front face)
       - VESA bolt holes through backplate + bosses
       - Cable exit cutouts at measured connector positions (HDMI, USB, 3.5mm audio)
       - Any speaker grille openings (from Task 1 measurements)

    **Design rules:**
    - Retention lips hold the screen from the front — the screen drops in from the back and
      the lips prevent it falling forward. No screws into the glass panel (per Research)
    - HDMI and USB exits must allow cable insertion without sharp bends (per Research pitfall 3)
    - 3.5mm audio port must be accessible (the Pi audio path goes through the screen, per
      project memory)
    - Print orientation: face-down on bed for best surface finish on the visible front face
      and optimal layer adhesion on retention lips (per Research)
    - All boolean subtractions use `+ 0.2` / `-0.1` convention


       Bracket geometry:
       ```
       BRACKET_ANGLE = 18;     // degrees back from vertical (per discretion: 15-20 deg)
       BRACKET_DEPTH = 60;     // base-to-screen distance (short cantilever, per pitfall 5)
       BRACKET_W     = 95;     // width — slightly wider than VESA spacing for stability
       BRACKET_THICK = 4.0;    // wall thickness — thicker than case walls for rigidity
       ```

       Dash mount block:
       ```
       DASH_BOLT_D     = 4.5;   // M4 clearance
       DASH_BOLT_HEAD  = 8.5;   // M4 counterbore
       DASH_BOLT_SPREAD = 70;   // bolt spacing on dash (measure dash before printing)
       BASE_THICK       = 4.0;  // base plate thickness
       ```

       Gusset block (per Research pitfall 5 — anti-resonance):
       ```
       GUSSET_THICK = 3.0;
       GUSSET_COUNT = 2;       // one each side
       ```

    4. Module `dash_bracket()` — a single piece:
       - Flat base plate with 2-4 M4 bolt holes for dash mounting (per D-10, direct bolt)
       - Angled riser from base to screen face at `BRACKET_ANGLE` degrees back from vertical
       - Screen face plate with VESA 75mm hole pattern (M4 clearance holes)
       - Two gusset triangles (one each side) bracing the angled riser to the base plate
         (per Research pitfall 5: prevents resonance at corrugated-road frequency)
       Minus:
       - VESA bolt holes through screen face
       - Dash bolt holes through base with counterbore
       - Weight-reduction cutout in the angled riser (large rectangular hole or pattern of
         circular holes) — reduces mass without reducing stiffness at the edges

    **Design rules:**
    - No articulating joints (per D-10) — the bracket is one solid print
    - Keep cantilever distance short (BRACKET_DEPTH <= 80mm) to avoid resonance (per
      Research pitfall 5)
    - Gussets are mandatory for vibration resistance — 40% infill minimum noted in slicer
      comments in file header
    - BRACKET_ANGLE = 18 degrees (per discretion, within 15-20 range recommended by Research)
    - Screen face must be within co-driver reach when seated (per D-11) — the short bracket
      depth keeps the screen close to the dash
    - Print orientation note in header: base flat on bed, angled face prints with support
  </action>
