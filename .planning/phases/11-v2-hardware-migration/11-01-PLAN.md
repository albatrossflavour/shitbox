      ```python
      sample = IMUSample(timestamp=time.time(), ax=ax, ay=ay, az=az, gx=gx, gy=gy, gz=gz)
      ```

    **1. Create src/shitbox/collectors/imu_heading.py** with:

    ```python
    """Artificial horizon + tilt-compensated heading via complementary filter.

    Fuses LSM6DSOX accel+gyro (from events.sampler.HighRateSampler) with
    LIS3MDL magnetometer (read here at 10 Hz) into pitch, roll, and
    tilt-compensated heading. Stored in SQLite for later consumers (driver
    display, dashboard). Heading is available at standstill — see D-12.
    """
    import math
    import threading
    import time
    from typing import Callable, Optional

    try:
        import board
        import busio
        from adafruit_lis3mdl import LIS3MDL
        _HAS_LIS3MDL = True
    except ImportError:
        _HAS_LIS3MDL = False

    from shitbox.collectors.base import BaseCollector
    from shitbox.storage.models import Reading
    from shitbox.utils.logging import get_logger

    log = get_logger(__name__)

    COMPLEMENTARY_ALPHA = 0.98  # trust gyro short-term, accel long-term
    ```

    Core classes:
    - `ComplementaryFilter`: holds `pitch`, `roll`, `_last_ts`. Method `update(ax, ay, az, gx, gy, gz, ts)`:
      ```python
      dt = ts - self._last_ts if self._last_ts else 0.01
      self._last_ts = ts
      accel_pitch = math.degrees(math.atan2(ay, math.sqrt(ax*ax + az*az)))
      accel_roll  = math.degrees(math.atan2(-ax, az))
      self.pitch = COMPLEMENTARY_ALPHA * (self.pitch + gx * dt) + (1 - COMPLEMENTARY_ALPHA) * accel_pitch
      self.roll  = COMPLEMENTARY_ALPHA * (self.roll  + gy * dt) + (1 - COMPLEMENTARY_ALPHA) * accel_roll
      ```
    - `tilt_compensated_heading(mx, my, mz, pitch_deg, roll_deg) -> float`:
      ```python
      p = math.radians(pitch_deg); r = math.radians(roll_deg)
      xh = mx * math.cos(p) + mz * math.sin(p)
      yh = mx * math.sin(r) * math.sin(p) + my * math.cos(r) - mz * math.sin(r) * math.cos(p)
      heading = math.degrees(math.atan2(yh, xh))
      return (heading + 360.0) % 360.0
      ```
    - `IMUHeadingCollector(BaseCollector)`: sample_rate_hz=10.0, subscribes to sampler via a `latest_sample_fn: Callable[[], Optional[IMUSample]]` passed in constructor. In `setup()` initialise LIS3MDL (graceful-absent pattern, same try/except as task 1). In `collect()`:
      1. Get latest IMU sample via `latest_sample_fn()`
      2. Read mag: `mx, my, mz = self._mag.magnetic` (microteslas)
      3. Update complementary filter with IMU sample
      4. Compute heading
      5. Return `Reading(sensor_type="imu_heading", value=heading, metadata={"pitch": self._filter.pitch, "roll": self._filter.roll, "mag_x": mx, "mag_y": my, "mag_z": mz})`
      6. Catch OSError/ValueError in the read path, log `sensor_read_error`, return None. Matches environment.py pattern.

      `# D-12: heading must be available at standstill. Filter runs unconditionally,`
