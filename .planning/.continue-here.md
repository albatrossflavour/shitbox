<decisions_made>

1. **Title card goes BETWEEN the intro and the footage**, not overlaid on footage.
   - Existing HUD burn-in (speed, G, event — shipped 2026-04-16 via ASS subtitles at save time) stays as-is. Title card is a separate slate.

2. **Render path: Pillow PNG → ffmpeg loop-to-MP4 → concat demuxer**.
   - Pillow gives full typographic control (kerning, coloured event bars, rounded corners) that `drawtext` cannot match.
   - ffmpeg one-shot loops the PNG into a 3-second MP4.
   - Dropped into the existing concat list in `src/shitbox/capture/ring_buffer.py::_concatenate_segments()` — same plumbing as the intro clip.

3. **Reverse geocoder is already in place** — `reverse_geocoder` library wired at `src/shitbox/events/engine.py:776-782`; `src/shitbox/sync/timelapse_compiler.py:92-115` has a reusable `_resolve_place_name(lat, lon)` pattern. No new dependency.

4. **Reuse the website event-colour palette** for the event badge:
   - HIGH_G `#da3633`, BIG_CORNER `#d29922`, HARD_BRAKE `#f85149`, ROUGH_ROAD `#8957e5`, MANUAL/BUTTON `#238636`, BOOT `#1f6feb`, ROLLOVER (new, colour TBD — suggest `#ff8000` or another red variant).
   - Keeps the video, dashboard, Grafana panels, and public site visually coherent.
</decisions_made>

<open_design_calls>

These need resolving during `/gsd-new-phase` for the title card work:

1. **Font choice** — does the existing ASS overlay (`src/shitbox/capture/overlay.py`?) use a specific font file, or just a system default? If there's a chosen font, reuse it; if not, pick one (Inter + IBM Plex Mono for coords is a safe rally-adjacent pairing).

2. **Card duration** — 3 seconds is a first guess. May want 2s for familiar viewers, 4s for first-time. Make it a config knob.

3. **Transition style** — hard cut, or fade-to-black → card → fade-to-footage? Hard cut is simpler; fade is nicer. Fade requires ffmpeg xfade or crossfade, adds complexity.

4. **GPS/geocoder fallback** — when no GPS lock or geocoder fails:
   - Option A: show coords only (`-20.7256, 139.4927`)
   - Option B: skip the location block entirely (card shows date + event only)
   - Option C: show "LOCATION UNKNOWN" placeholder
   Pick one before the plan is written.

5. **Manual/button-press events** — no specific event type. Options:
   - Show "MANUAL CAPTURE" in the green MANUAL colour
   - Include button press reason if it was tagged in the event (check Event dataclass for relevant fields)

6. **Config knobs** — at minimum:
   - `capture.title_card.enabled: true/false` (disable if it gets annoying)
   - `capture.title_card.duration_seconds: 3.0`
   - `capture.title_card.transition: cut|fade`

7. **Output resolution / canvas** — match the composited output (1920×1080 or whatever the post-PiP composition is). Need to confirm the final video resolution post-PiP; the card must match or ffmpeg will reject the concat.

8. **Where the card lives in the concat list** — after the intro, before the pre-event buffer segments. Intro is ~7.97 seconds (cached via ffprobe). Card is appended next. Then buffer segments. The `pip_compositor` sync offsets already account for intro duration — adding a card changes the total pre-footage timing and may affect any offset calc (check `total_offset = intro_duration + sync_offset` logic in pip work — memory file `project_pip_sync_fix.md` has the context; or grep `intro_duration` in `src/shitbox/capture/`).
</open_design_calls>
